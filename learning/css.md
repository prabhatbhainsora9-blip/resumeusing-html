# Day 4 CSS Learnings

Today I learned that HTML gives a website its structure, while CSS controls how it looks. CSS can change colours, spacing, fonts, sizes, borders, and page layout without changing the HTML content.

I learned three ways to add CSS: inline CSS, internal CSS inside a `style` tag, and external CSS in a separate file. External CSS is the best option for a real project because it keeps the HTML clean and lets one stylesheet be reused on multiple pages.

I practised selectors such as element selectors, class selectors, and ID selectors. I also learned that the browser reads CSS rules from selectors and applies them to matching HTML elements. The box model helped me understand the difference between margin, border, padding, and content.

For this task, I used an external `style.css` file, linked it with `href="./style.css"`, and added hover effects to links and buttons. I also used Flexbox to arrange content and media queries to make the resume readable on smaller screens.
