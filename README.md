Personal Resume 

This repository contains my personal resume website, CSS learning notes, three CSS practice projects, and a redesigned resume revamp.

## About the Project

This project was created as part of the Day 3, Day 4, and Day 5 take-home tasks. It begins with a semantic HTML resume, adds external CSS styling and practice projects, then improves the resume in a separate revamp folder.

## Features

- Header with name, tagline, photo, and caption
- Navigation links to each resume section
- About Me, Education, Skills, Projects, Hobbies, and Contact sections
- Education table
- Ordered and unordered lists
- Expandable project information using `details` and `summary`
- GitHub and LinkedIn profile links
- Simple contact form with inputs and a submit button
- Semantic HTML5 layout
- External CSS styling with responsive layout and hover effects
- CSS learning notes and three mini projects
- A separate Day 5 resume revamp with improved structure and design

## Mandatory HTML Tags Used

`header`, `footer`, `nav`, `aside`, `section`, `article`, `hgroup`, `ul`, `ol`, `li`, `table`, `details`, `summary`, `figcaption`, `img`, `form`, `input`, and `button`.

## Run Locally

1. Download or clone this repository.
2. Open `index.html` in any web browser.

## CSS Practice Projects

- **Profile Card:** Photo, name, bio, and contact button.
- **Navigation Bar:** Horizontal responsive menu with hover effects.
- **Button Collection:** Three button styles with individual hover states.

## Day 5 Revamp

The `revamp` folder contains an improved version of the resume while preserving the original version for comparison.

- Cleaner semantic HTML structure and logical heading order
- Contact details grouped with the `address` element
- Improved education table with a caption and accessible headings
- Project articles with working links to related work
- Responsive external stylesheet and hover effects
- No `div` or `span` tags

To view the revamped version, open `revamp/index.html` in a browser.
